## What This Project Does

✓ Analyzed 12 months of sales data (Jan-Dec 2022)  
✓ Cleaned & processed multi-dimensional order data  
✓ Created pivot tables for geographic, demographic & channel analysis  
✓ Built interactive Excel dashboard with 6+ visualizations  
✓ Identified actionable business insights  

---

## Key Findings

1. **Customer Base**: Women drive 64% of sales → primary marketing target
2. **Geography**: Top 5 states (Maharashtra, Karnataka, UP, Telangana, TN) dominate revenue
3. **Channels**: Amazon & Flipkart lead with 57% combined order share
4. **Operations**: 92% delivery success rate shows strong logistics capability
5. **Demographics**: Adult segment (35% of orders) most valuable, especially women
